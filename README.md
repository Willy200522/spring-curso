# Spring-hibernate

Tutorial de Hibernate ORM con Spring Framework

Este proyecto es la guia del tutorial de Juan Diaz(Pildoras Informáticas) sobre cómo integrar Hibernate ORM con Spring Framework 
para gestionar la persistencia de datos en una aplicación Java. Proporciona ejemplos prácticos de configuración, mapeo de entidades y operaciones CRUD utilizando Hibernate en un entorno Spring.

## Requisitos previos

- Conocimientos básicos de Java y Spring.
- Familiaridad con bases de datos relacionales.
- Entorno de desarrollo Java (JDK 8 o superior).
- Maven o Gradle para la gestión de dependencias.
- Base de datos relacional (MySQL, PostgreSQL, etc.) configurada y en funcionamiento.
- IDE como IntelliJ IDEA, Eclipse o Spring Tool Suite.
- Dependencias necesarias en el archivo pom.xml o build.gradle.

## Configuración del proyecto

1. Configura las dependencias de Hibernate y Spring en tu archivo `pom.xml` o `build.gradle`.
2. Configura el archivo XML de Hibernate dentro de resources (incluye configuraciones básicas de sesión)

## Estructura del proyecto

- `src/main/java`: Contiene el código fuente de la aplicación.
  - `com.william.connectionHibernate`: Pruebas de conexión y registro de datos en mysql.
